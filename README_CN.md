## 🌟 创世愿景

今天的数字世界被两座大山死死压着：
1. **程序员的困境**：无数优秀的开源作者和极客，用无数个不眠之夜写出了支撑整个互联网的底层代码和算法，却只能“用爱发电”或者沦为大厂的廉价螺丝钉，无法获得长久、体面的被动收入。
2. **普通人的困境**：99% 的普通人、小微店主和创业者，明明有着绝佳的商业想法，却因为不懂编程、不会写代码，而被高高的技术高墙死锁在数字大门之外。

**SSU 协议（Sovereign Code-Skill Unit，主权代码-技能单元）** 的诞生，就是为了用最纯粹的技术，砸碎这两座大山：
* **对普通人**：把高高在上的代码与 AI 技能打包成开箱即用的 SSU 单元。像在应用商店买菜一样，扫码即付，一键挂载，让天下没有难用的生产力。
* **对全球程序员**：你写下的每一个硬核 Skill 或算法模块，在交易所里都拥有不可篡改的主权指纹。只要全球有节点在调用它，系统就会自动、秒级、无中介地将永续微型版税打入你的钱包。

## 💳 双轨清算与法币网关规范

为了照顾全球不同群体的支付习惯，协议内置了严密的**双轨清算底座**：

1. **轨道一 / 法币直购通道 (Fiat Gateway)**：
   * 针对非技术普通用户。支持微信、支付宝、信用卡等日常支付方式。
   * 服务端采用 HMAC 一次性防重放验证，买家付法币，节点零存储敏感卡号数据（`no card data on node`）。
2. **轨道二 / 链上稳定币通道 (Stablecoin Gateway)**：
   * 针对全球开发者、节点提供商和交易员。
   * 支持 USDC / USDT 等主流稳定币的精准转账与哈希凭证校验，实现毫秒级、无国界的永续版税划拨。
