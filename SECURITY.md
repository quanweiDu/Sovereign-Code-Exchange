| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability
If you discover a security vulnerability within the SSU Protocol (e.g., within the HMAC fiat gateway or meta-kernel quarantine sandbox), please report it responsibly. Do not create public GitHub issues. 
Instead, please contact the maintainer directly or submit a private advisory.
